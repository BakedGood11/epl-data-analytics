# Arsenal Python Analysis

This directory contains Jupyter notebooks for analyzing and predicting results related to Arsenal FC. The notebooks utilize Python and various data science libraries to build and evaluate predictive models.

## Notebooks

- **(p)redicting-results.ipynb**: This notebook contains the initial analysis and model for predicting match results.
- **(p)redicting-results.refactor.ipynb**: A refactored version of the original notebook, with improved code structure and adjusted approach.
